# 3. 前回からの判断の変更

本日の実測により、2026-10-11 午前に提出した2文書の記述のうち**2点を改める**。

## 3.1 【変更】観測年次の問題は「区部 vs 多摩」ではなく「図郭ごとの計測季節」

**前回の記述：** 多摩と区部で点群の整備時期が異なるため、Control を多摩に限定すれば観測条件が揃う（ただし未確認の補強材料と明記）。

**実測で判明したこと：** 多摩地域の計測年月日は **2022年7月〜2023年1月**。すなわち**多摩地域の内部で、着葉期（7〜10月）と落葉期（12〜1月）の図郭が混在している**。区部は2023年3月〜4月（展葉前〜展葉期）。

**したがって：**

> **Control を多摩に限定しても観測条件は揃わない。**制約は地域ではなく、**図郭ごとの計測日（季節）**に対して課さなければならない。

**【撤回】** 当初はLASヘッダから図郭単位の計測日を取得できると述べたが、これは誤りである（冒頭の撤回表を参照）。公式測量メタデータを入手できれば、

- 各公園に `survey_date` と `leaf_season` を付与する
- matched pair を**同一季節区分内に限定する**

という制約が、推測ではなく実データに基づいて実装可能である。

**なお、Control を多摩に限定するという提案自体は撤回しない。**その根拠は観測条件ではなく、`pipeline_verification_report_20261011.md` §2.2 根拠1 ——Treatment 30件が全件多摩にあり、区部の公園とペアを組むと交通量・建物密度が Treatment とほぼ完全に交絡する—— にあり、こちらは検証済みの事実のみに依存する。

## 3.2 【変更】「0.25mは参考データ」問題は本手法には当たらない

**前回の懸念：** 多摩の0.25mグリッドは「参考データ」（仕様は0.5m）であり、これを解析グリッドにしてよいか。

**整理：** 本ワークフローは**都が配布するグリッド製品を使わない。**LAS点群から自前で0.25mグリッドを構成する。したがって「参考データ」という位置づけは本手法に直接は及ばない。

ただし**0.25mを選ぶこと自体の妥当性は別途要る。**実測点密度は 77点/m²（0.25mセルあたり平均約4.8点）であり、0.25mセルは十分に充填される。実際 DSM の空セルは園内 0.8% にとどまった。この実測値が 0.25m 採用の根拠となる。

**論文には「都の0.25mグリッド製品ではなく、LAS点群から独自に0.25mグリッドを生成した」と明記すること。**

## 3.3 【変更】植生判定アルゴリズムを分光単独から構造＋分光に改める

**前回の定義：** 植生判定は ExG（近赤外がない場合）で行う。

**実測に基づく改訂：**

```
is_vegetation = (多重反射率 >= 0.20) OR (ExG > 0.02)
```

**根拠：** §2.4 のとおり、計測が落葉期（2023-01-05）であるにもかかわらず、多重反射率は樹冠 0.73 / 地表 0.00 と明確に分離した。分光指標のみに依存すると、落葉樹の樹冠を取りこぼし、かつ冬季の裸地を草地と誤判定する。

**この改訂は研究ノートのFIXED事項には抵触しない**（アルゴリズムの細部は従来未定であったため）。
