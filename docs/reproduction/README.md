## 読むときの注意（研究の問いの更新について）

- これらの文書は作成時点で、研究の問いを **「誤った地図情報を与えたときに判断がどう変わるか」** という旧案で記述している
  （特に `FP_NAV_FEASIBILITY_REPORT.md` §4・§7 の新規性議論）。
- その後、独自研究の方向は **「地図の内容は正しいまま、表示方向だけを変える」**（[`../future_work.md`](../future_work.md)）へ更新された。
  「誤った/不正確な地図で性能が落ちる」という発見は先行研究で既出のため、**本研究の新規性としては主張しない**。
- したがって、本フォルダの**新規性に関する議論は旧案時点の記録**として読むこと。一方で、**コード経路・入出力仕様・環境制約・
  mac向け改変の技術的内容は現在も有効**であり、再現実験の基礎資料として使う。

> これらは歴史的記録として原文のまま残している（研究過程の可視化のため）。更新は上書きではなく、
> 本注記や [`../research_progress.md`](../research_progress.md) 側で差分を明示する方針。
