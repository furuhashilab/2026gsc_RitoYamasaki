# 1. 指摘① — DEMホールドアウト検証を実施した

## 1.1 指摘の要旨

> グリッドを大きくすると1セル内に少なくとも1点の地表リターンが入る確率は当然高まる。これは DEM の精度が上がったことを直接示すものではない。地表点の一部を検証用に取り分け、残りから DEM を再構築して標高誤差を比較せよ。樹冠下など地表点の少ない場所も別途評価せよ。

**方法論として完全に正しい。**`ground_observed_ratio` は「補間しなくてよいセルの割合」であって「補間値の正確さ」ではありません。私はこの2つを混同して 0.5m を推していました。

## 1.2 実施した検証

図郭 09LC2948 全域（400×300 m、公園・住宅・道路を含む混合地被）の地表点（classification=2）を対象に、2通りのホールドアウトを行いました。

- **無作為セル・ホールドアウト:** 地表点を含むセルの20%を無作為に選び、そのセルの地表点を全除去
- **塊状ホールドアウト:** 2m角／4m角のブロックの20%を選び、ブロック内の地表点を全除去（**樹冠下の連続した空白を模擬**）

残りの地表点から DEM を構成し、最近傍補完で穴を埋め、保留セルの真の最低地表高と比較しました。`DSM − 真の地表高 ≥ 3m` のセルを「樹冠下」として層別しています。

## 1.4 読み取れること

**(a) 0.25 m がすべての条件で最も誤差が小さい。**無作為・塊状のいずれでも、また樹冠下・開空地のいずれでも、解像度を粗くすると誤差は単調に増えます。

理由は単純です。最近傍補完の誤差は**メートル単位の補間距離**に支配されます。0.25 m グリッドでは空セルの最近傍が物理的に 0.25 m 先にありますが、1.0 m グリッドでは 1.0 m 先です。地表観測率が高くても、1セルあたりの補間距離が長ければ誤差は大きくなります。

> **したがって `ground_observed_ratio` を根拠に 0.5 m を推した昨日の判断は誤りでした。撤回します。**
> ご指摘の「地表点の有無だけでは DEM の精度を示さない」は、まさにこの誤りを突いたものです。

**(b) DEM 補間誤差は樹高閾値に対して小さい。**最悪条件（0.25 m・4m角ブロック・樹冠下）でも RMSE は 0.303 m で、**h_tree = 3.0 m の約10%**です。無作為ホールドアウトなら 0.083 m（2.8%）。

> **DEM 補間は Forest/Grass 判別の律速要因ではありません。**解像度を 0.25 m と 0.5 m のどちらにするかという問題は、DEM 側ではなく **DSM 側（混合セルの扱い）** の問題として扱うべきです。Forest% の 5.47 ポイント差は、セル内最高点を DSM とすることで粗いグリッドほど樹冠が隙間を埋める効果に由来しており、これは独立判読でしか決着しません。

**(c) ただし本検証の限界。**ホールドアウトは「元々地表点があったセル」の復元精度を測るものです。**真に地表点が1点も取得できなかった領域**（極端に密な常緑樹冠の下など）の誤差は、原理的にこの方法では測れません。ご指摘の「樹冠下など地表点の少ない場所についても別途評価が必要」はその意味で未解決として残ります。4m角ブロックでの評価が現時点の最良近似です。

## 1.5 F6 の改訂

> 確定条件は DEM 側ではなく、0.25/0.5 m それぞれの分類結果を独立判読と比較すること（§3）。

# 2. 指摘② — LAS の RGB の出所

## 2.1 先に、本ラウンドで私が作ったバグの自己申告

RGB 診断の初回実行で、`2*G - R - B` を **uint16 のまま計算**し、オーバーフローで符号が反転した値を出していました（「開空地の地表点 ExG 中央値 0.681」など）。同一セッション内で検出し float64 で再計算しています。

**本番パイプラインには影響しません。**`landcover_pipeline.py` は RGB を float64 配列に格納してから計算しており、オーバーフローは起きません。以下の数値はすべて訂正後のものです。

## 2.2 鉛直オルソ・ドレープかどうかの判定

RGB が単一の鉛直オルソ画像から投影（ドレープ）されたものなら、**同一の XY 画素に落ちる点は高さによらず同色**になるはずです。これを直接検定しました。

0.20 m（オルソの地上画素寸法に相当）の XY セルに全点を割り当て、**セル内の Z 幅が 3 m を超える**セル（＝樹冠と地面の両方の点を含むセル）を抽出しました。

| 項目 | 値 |
|---|---:|
| 対象セル数 | 572,938 |
| **セル内で RGB が完全に一定のセル** | **0.04%** |
| セル内の R のレンジ（max−min）中央値 | 900 / 65,535 |

> **単純な鉛直オルソ・ドレープではありません。**同一 XY・異なる高さの点は異なる色を持ちます。
>
> なお、当初は同一パルスの first/last return を突き合わせる検定を試みましたが、`gps_time` が 50万点中 42万値しか相異ならず（重複多数）**パルスを一意に識別できない**ため、この方法は無効と判断して破棄しました。上記の XY セル法に置き換えています。

## 2.3 しかし、ご懸念の実質は残る

ドレープでないことは分かりましたが、**RGB の元画像がいつ撮影されたものかは LAS から判定できません。**ご指摘のとおり、LAS 規格上 RGB は補助データ由来であり、LiDAR 計測と同時とは限りません。

実害の有無を測るため、**地表点（class 2）の ExG を樹冠の有無で層別**しました。

| 地表点の位置 | n | ExG 中央値 | ExG > 0.02 の割合 |
|---|---:|---:|---:|
| 樹冠下（セル内の高さ差 ≥ 3 m） | 323,343 | **+0.028** | **55.0%** |
| 開空地（高さ差 < 0.5 m） | 1,276,403 | **−0.011** | **15.4%** |

**樹冠下の地表点のほうが有意に「緑」寄りです。**ただしこれは2通りに解釈できます。

- (i) RGB が上空の樹冠の色に汚染されている（ご懸念どおり）
- (ii) 樹冠下の地面に実際に下層植生・落葉・コケがある（物理的に当然ありうる）

**LAS 内の情報だけでは (i) と (ii) を区別できません。**独立参照データ（判読）が必要です。

## 2.4 判定と対応

> **ご指摘を受け入れます。**「LAS に RGB があるからオルソ不要」という昨日の記述は、*別ファイルを取得する手間が不要* という意味に限定し、**RGB の時点整合性が保証されるという含意は撤回**します。
>
> 確認すべき事項を測量日と同じ優先度に引き上げます：
> 1. RGB の元画像の撮影時期
> 2. LiDAR 計測時期との一致
> 3. 樹冠下の地表点の RGB がどう付与されたか（最近傍画素か、オクルージョン考慮か）
>
> いずれも**東京都の公式測量メタデータ／製品仕様書**で確認します。測量日（F12 の代替）と同一の資料で解決する見込みです。

# 3. 指摘③ — 精度評価の設計（受け入れ、具体化）

ご提案の4点をそのまま骨格に採用します。

## 3.1 対象公園の選定（無作為ではなく意図的に）

ランダム100点判読だけでは少数クラスを評価できない、というご指摘のとおりです。**クラスの出現を保証する目的標本抽出**とします。

| 層 | 必須要件 | 園数 |
|---|---|---:|
| A 水面あり | 池・流れを含む（姿見の池緑地 ほか） | 3 |
| B 人工構造物あり | 建物・東屋・大型遊具を含む | 3 |
| C 落葉樹優占 | 樹冠の季節変化が大きい | 3 |
| D 草地・運動場優占 | 低層植生が主体 | 3 |
| E 小面積（< 1,000 m²） | 境界誤差の影響が大きい | 3 |
| F 無作為抽出 | 上記以外からランダム | 6 |
| | | **21** |

## 3.2 較正用と評価用を分ける

> **較正用 9 公園**（各層から1〜2）で閾値（pen, ExG, h_tree, 水面最小面積）を決める。
> **評価用 12 公園**は閾値決定が終わるまで一切見ない。最終精度は評価用のみで報告する。

これは機械学習の train/test 分離に相当します。較正と評価を同じ公園で行うと精度が楽観側に偏ります。**閾値の決定はすべて音響アウトカムを見る前に完了させます。**

## 3.3 判読と報告する指標

- **点判読:** 1公園あたり 100 点。ただし単純無作為ではなく**クラス層化**（各クラス最低15点、不足分は無作為）。クラス別 precision / recall が少数クラスでも推定できるようにする
- **面積判読:** 各公園で 20m×20m の方形区を2つ全面判読し、**公園単位の被覆率誤差**を直接測る（点判読だけでは面積率の偏りが分からない）
- **報告:** クラス別混同行列、precision / recall、全体精度、Kappa、**公園単位の Forest/Grass/Water 被覆率の誤差（bias と RMSE）**
- **判読者:** 1名。ただし評価用のうち3公園は時間をおいて再判読し、**判読自体の再現性**を報告する

## 3.4 最終エンドポイント — マッチング安定性

**これが最も重要というご指摘に同意します。**卒論の目的は高精度な土地被覆分類ではなく、内部自然環境が類似する公園を妥当に選ぶことです。

> **分類誤差を被覆率に注入したときに、選ばれる matched Control がどれだけ変わるかを測る。**
>
> 手順：§3.3 で得た公園単位の誤差分布（bias と RMSE）から、各候補公園の Forest/Grass/Water にノイズを加えたブートストラップ標本を 1,000 回生成し、そのたびにマッチングを実行する。報告する指標は、
> - 各 Treatment について**最良 Control が変わらない確率**
> - 上位3位以内に残る Control の集合の安定性（Jaccard係数）
> - 最終10組のうち何組が入れ替わるか
>
> **安定していれば、分類精度が完璧でなくてもマッチングは防御できる。**逆に不安定なら、分類精度を上げるか、マッチング変数を減らすか、ペア数を増やす必要がある。

この設計は k の感度検証（k = 30 / 50 / 100）と同じ枠組みで回せます。
