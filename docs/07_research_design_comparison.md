# 研究デザイン比較 — 何を揃えて比較するか

作成日: 2026-10-20
対象: 卒業論文（東京都条例に基づく緑地保全地域と重複する都市公園の音環境に関する比較研究）
位置づけ: 設計変更の提案ではなく、指導教員と検討するための比較材料

---

## 0. 比較する4つのデザイン

| 記号 | デザイン | マッチング変数 | 現在の状態 |
|---|---|---|---|
| **A** | 現行設計 | 公園面積 + 樹冠被覆率（Forest%）<br>（拡張: + 低層植生率、+ 水域率） | **実装済。8ペア成立（S3: 面積比 0.667–1.5、\|Δ樹冠\| ≤15pt）** |
| **B** | 面積のみ | 公園面積 | **未計算**（既存の面積データのみで数分で計算可能） |
| **C** | 面積 + 地域条件 | 公園面積 + 周辺市街化度 + 主要道路からの距離 + 自治体 | **未計算**（周辺条件のGIS算出が未実施） |
| **D** | 面積 + 土地被覆 + 地域条件 | A と C の全変数 | **未計算**（C の前提が必要） |

**重要**: D を最良と前提しません。変数を増やすほどペア数が減り、交絡の統制と推定量の明確さがトレードオフになります。また B を「単純だから」という理由で推奨しません。B と C は**主要RQの書き換えを伴います**（§3）。

## 2. 因果構造の2つの想定（DAG）

疑問A の核心は「指定が土地被覆に影響したのか、土地被覆が指定を正当化したのか」です。一次資料は**両方が起きている**ことを示しており、これが設計判断を難しくしています。

### 2.1 一次資料が示す時系列

- 条例第17条第1項第5号の指定要件は「**樹林地、水辺地等が単独で、又は一体となって自然を形成している**」区域であること。→ **指定時点で既に樹林・水辺が存在していることが指定の前提**。
- 各保全地域のページには「**指定時の植生**」が記録されている。→ 指定時の植生は**処置前変数**として存在する。
- 条例第18条第2項第4号により保全計画は「**植生管理に関する事項**」を定め、実際の保全の方針には「現在の高木層を維持する」「明るい雑木林として保全する」「シバ草地は二次草地とする」等の管理指示が含まれる。→ **指定後の植生は処置後変数**。
- 緑地保全地域の指定年月日は昭和50年代〜令和（最古は昭和50年代、本研究の Treatment に関わる例として矢川 昭和52年、小山 平成元年、宇津木 平成4年、国分寺姿見の池 平成5年、多摩東寺方 平成19年）。LiDAR 計測は 2022年7月〜2023年1月（多摩地域）。→ **本研究が測定している Forest% は、指定の数十年後の状態**。

### 2.2 DAG 1 — 「土地被覆が指定を正当化した」（指定前の自然性が指定を決めた）

```
  指定前の自然性 (樹林地・水辺地の存在)  ──→  指定 (緑地保全地域)
          │                                      │
          │                                      │
          ↓                                      ↓
  現在の土地被覆 (Forest%) ─────────────→  音環境 (相対音レベル)
          ↑
          │
  立地・地形 (崖線・丘陵) ──────────────→  音環境
          │
          └────────────────────→  指定
```

この構造では、**指定前の自然性**が交絡因子であり、現在の Forest% はその代理です。Forest% でマッチングすることは交絡の統制として正当化されます。

### 2.3 DAG 2 — 「指定が土地被覆を維持した」（指定後の管理が植生を決めた）

```
  指定前の自然性  ──→  指定  ──→  植生管理 (保全計画)  ──→  現在のForest%
          │              │                                        │
          │              │                                        ↓
          │              └──────────────────────────────→  音環境
          ↓                                                       ↑
  立地・地形 ───────────────────────────────────────┘
```

この構造では、現在の Forest% は**指定の下流（媒介変数）**です。Forest% でマッチングすることは媒介経路の遮断であり、「指定の総合的な関連」を推定したいなら過剰調整になります（Rosenbaum 1984; Schisterman et al. 2009）。

### 2.4 実際の構造（両方が成り立つ）

```
  立地・地形 (崖線・丘陵) ──┬──────────────→  指定
                            │                    │
                            │                    ├──→ 植生管理 ──┐
                            │                    │                │
                            ↓                    ↓                ↓
                 指定前の自然性 ──────────→ 現在のForest% ←───┘
                            │                         │
                            │                         │
                            ↓                         ↓
                        周辺条件 ──────────────→ 音環境
                     (道路・市街化度・交通量)         ↑
                            └────────────────────┘
```

**現在の Forest% は交絡因子の代理であると同時に媒介変数でもあります。** この場合、Forest% を「交絡統制のために揃える」とも「媒介遮断だから揃えるべきでない」とも一義的には言えません。

**ここで効くのが、Schisterman, Cole & Platt (2009) による過剰調整バイアスの定義です**（抄録本文を PubMed PMID 19525685 で確認済）。同定義は「**曝露からアウトカムへの因果パス上にある中間変数（またはその下流の代理変数）の制御**」であり、どの因果パスを含む対比を推定しようとしているかを前提にしています。したがって、ある変数の制御が過剰調整にあたるか否かは推定したい対比に相対的に決まる、というのが定義からの帰結です（**この適用は私の推論であり、同論文が本研究について述べていることではありません**）。本研究の固定RQ は「内部自然環境特性が類似する都市公園を比較したとき」と明示しているので、Forest% を揃えた条件付き対比が推定したい量そのものです。したがって**現行設計Aは、固定RQの下では方法論的に擁護できます**。

### 2.5 残る未解決の問題

DAG から読み取れる、現行設計Aでも残る問題は次の1点です。

> **立地・地形 → 周辺条件 → 音環境** の経路が統制されていない。

Forest% を揃えても、崖線・丘陵に立地する Treatment と、平坦市街地に立地する Control とでは、周辺道路条件が系統的に異なる可能性があります。これは Forest% のマッチングでは解決しません。**疑問C（周辺道路・来園者）を「記録するだけ」にとどめるか、設計Cに移るかの判断は、この経路の重要性をどう見るかで決まります。**

**実行可能な中間案（私の提案）**: 設計A を維持したまま、**周辺条件を事後的な記述変数として測定し、ペアごとに併記する**。8ペアそれぞれについて (i) 最寄り主要道路までの距離、(ii) 500 m バッファ内の建物面積率、(iii) 自治体 を表に加える。これにより、「周辺条件が大きく違うペア」を特定でき、感度分析（そのペアを除いた場合の結果）が可能になります。追加のLAS処理は不要で、既存の土地利用現況データと公園ポリゴンで計算できます。

## 3. RQ-1 と RQ-2 の比較

### RQ-1（現行・固定版）

> 内部自然環境特性が類似する都市公園を比較したとき、自然保全指定のある公園とない公園では、標準化された録音条件下で観測される音環境に体系的な差があるか。

| 項目 | 内容 |
|---|---|
| 対応する設計 | **A**（面積 + 土地被覆） |
| 推定される対比 | 内部植生が同程度の公園間での、指定の有無に伴う音環境の差 |
| マッチング変数の性格 | Forest% は「交絡因子の代理」かつ「媒介変数」。RQ が条件を明示しているため、過剰調整の批判は回避できる |
| 強み | 既に 8ペアが確定。追加GIS不要。「植生だけでは説明されない差があるか」という明確な問いに答えられる |
| 弱み | 政策評価としては読めない。周辺条件の交絡が残る |
| 指定と土地被覆の前後関係の扱い | DAG 2.4 の通り双方向。RQ が条件付き対比を明示することで回避 |

### RQ-2（代替案）

> 同規模かつ同様の都市文脈に立地する都市公園を比較したとき、自然保全指定のある公園とない公園では、標準化された録音条件下で観測される音環境に体系的な差があるか。

| 項目 | 内容 |
|---|---|
| 対応する設計 | **C**（面積 + 地域条件） |
| 推定される対比 | 同規模・同文脈の公園間での、指定の有無に伴う総合的な音環境の差（植生経路を含む） |
| マッチング変数の性格 | すべて処置前ないし指定の影響を受けにくい変数。保全政策評価の標準構造（Andam et al. 2008 と同型） |
| 強み | 政策含意が読みやすい。立地交絡に強い。過剰調整の批判を受けない |
| 弱み | **周辺条件のGIS算出が未実施**。提出期限への影響が大きい。土地被覆のマッチング結果（8ペア）を主解析に使えなくなる |
| 指定と土地被覆の前後関係の扱い | 問題にならない（土地被覆をマッチングに使わないため） |

### どちらを選ぶかの判断軸

| 問い | RQ-1 | RQ-2 |
|---|---|---|
| 「保全指定された公園は実際に静かなのか」を問いたい | 答えられない | **答えられる** |
| 「植生の違いを除いても、指定の有無で音環境に差があるか」を問いたい | **答えられる** | 答えられない |
| 2027-01-08 に提出できるか | **現時点で可能** | 追加工程が必要 |
| 既存のLiDAR作業（109公園分の Forest%）が活きるか | **主解析で使われる** | 記述統計・層別でのみ使われる（完全に無駄にはならない） |

**私の見解（提案であり結論ではありません）**: RQ-1 を主解析として維持し、§2.5 の中間案（周辺条件を記述変数として併記）を採ることで、RQ-2 の問題意識に部分的に応答する構成が、妥当性と期限の両立として最も現実的だと考えます。指導教員が「政策評価として読みたい」と判断した場合のみ RQ-2 への移行を検討すべきで、その場合は提出スケジュールの再設計が必要です。

## 4. 因果概念の使用範囲についての注意

本文書は因果推論の概念（過剰調整、媒介、コライダー、選択バイアス）を用いていますが、これは**限界の理解のため**であり、因果効果の推定を意図するものではありません。本研究は一貫して「関連（association）」を報告します。

具体的に避けるべき記述:

- ×「指定の効果は X dB だった」
- ×「植生の影響を除いた指定の直接効果」
- ×「面積のみのマッチングとの差は植生を介した媒介効果である」
- ○「内部植生が同程度の公園間で、指定のある公園の相対音レベルは平均 X dB 低かった（高かった）」
- ○「面積のみでマッチングした補助解析では差が Y であり、2つの対比は異なる推定量である」
