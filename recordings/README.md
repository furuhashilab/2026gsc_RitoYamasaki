# recordings/

現地録音データの置き場所。音声ファイルは `.gitignore` で除外しています。

録音時に記録すべき項目は [`../fieldwork/field_reconnaissance_checklist.md`](../fieldwork/field_reconnaissance_checklist.md) の §3 を参照してください。

命名規則の提案: `<pair_id>_<role>_<park>_<YYYYMMDD>_<HHMM>_<point>.wav`
例: `P01_T_とりで公園_20270115_1030_pt1.wav`

**ペアの両公園は同じ時期・近い時間帯に録音してください**（植生の減衰効果には季節変動があるため: Tashakor & Chamani 2021）。
